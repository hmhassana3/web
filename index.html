Reset Locker

Forgot the locker password? It cannot be recovered. You can delete the Locker and all locked websites, then create a new one.

Locked websites are encrypted (AES-256) with your locker password before they are saved or published, so visitors and GitHub cannot read them without it. The locker password is separate from the admin password.
Publish to Everyone (GitHub Sync)

One-time setup per device. After connecting, every change you save is automatically published for all visitors, from any phone, with no laptop needed. Changes go live in about 1 minute.

Backup & Restore

Admin data is kept in this browser (localStorage) and, once GitHub Sync is connected, also in your repository as sites.json. Export a JSON backup now and then.
